01

화면 구성과 기본 조작

조합 화면은 단위 마법을 고르는 도구 모음, 흐름을 설계하는 편집창, 결과를 확인하는 미리보기로 나뉩니다.

01

상단 도구 모음

속성·행동·조절·확장 탭으로 노드를 찾습니다. 프리셋 관리와 전체 초기화도 이곳에서 실행합니다.

02

마법 편집창

노드를 배치하고 핸들을 연결하는 작업 공간입니다. 선의 화살표가 실제 마나 진행 방향을 나타냅니다.

03

유효한 연결이 생기면 서클 수, 각 서클의 모습과 스탯, 전체 조합의 Total Stats가 즉시 갱신됩니다.

02

첫 마법 만들기

처음에는 분기나 반복 없이 직선 조합부터 만들어 보세요. 핵심은 마나근원과 최종발현 사이에 끊김 없는 경로를 만드는 것입니다.

  1. 카테고리 선택

    속성부터 시작해 행동·조절 노드를 골라 봅니다. 카테고리 탭은 여러 개를 동시에 켤 수 있습니다.

  2. 스탯 확인 후 배치

    마법 버튼에 커서를 올리면 설명과 기본 스탯이 보입니다. 클릭하거나 드래그해 필요한 노드를 놓습니다.

  3. 마나근원에서 출발

    화면 아래쪽의 마나근원 위쪽 출력점을 첫 단위 마법의 아래쪽 입력점에 연결합니다.

  4. 아래에서 위로 연결

    각 노드의 위쪽 출력점 → 다음 노드의 아래쪽 입력점 순서로 연결하고 마지막은 최종발현에 잇습니다.

  5. 결과 조정

    미리보기에서 서클과 Total Stats를 확인합니다. 노드를 추가·제거하거나 순서를 바꾸며 결과를 조정하세요.

  6. 시그니처 마법 기록

    서클이 하나 이상 만들어지면 시연 시작이 활성화됩니다. 마법 이름과 설명을 적으면 조합이 완성됩니다.

불꽃 투사

마나근원 → 발화 → 지정 → 방출 → 최종발현

얼음 구속

마나근원 → 냉각 → 지정 → 성형 → 유지 → 최종발현

바람 추적

마나근원 → 공기 → 감지 → 이동 → 최종발현

03

노드 읽기와 연결 규칙

출력 · 다음 노드로 ⇧ 증폭 화력 강화 입력 · 이전 노드에서
  • 위쪽 핸들 = 출력 현재 노드에서 다음 노드로 마나를 보냅니다. 연결선의 화살표도 같은 방향을 가리킵니다.
  • 아래쪽 핸들 = 입력 이전 노드의 출력을 받아옵니다. 확장 노드는 여러 입력 또는 출력을 가질 수 있습니다.
  • 아이콘·이름·캡션 아이콘과 이름은 단위 마법의 종류를 나타냅니다. 우클릭하면 모든 일반 노드에 캡션을 붙일 수 있습니다.
  • START END CYCLE 배지 START는 들어오는 연결이 없음, END는 나가는 연결이 없음을 뜻합니다. CYCLE은 반복 연결을 받을 수 있는 추가 입력점입니다.
01

완성 경로만 계산

마나근원에서 출발해 최종발현에 도착하는 경로 위의 일반 노드만 서클과 스탯에 반영됩니다.

02

기본은 입력·출력 1개

대부분의 단위 마법은 입력 하나와 출력 하나만 가집니다. 같은 핸들에 다시 연결하면 기존 선이 교체됩니다.

03

시스템 노드는 고정

마나근원은 입력 없이 여러 출력을, 최종발현은 출력 없이 여러 입력을 받을 수 있으며 삭제할 수 없습니다.

04

확장 노드는 예외

분기·분리는 여러 출력을 만들고, 병합은 여러 입력을 하나의 출력으로 모읍니다.

05

순환은 반복만 허용

일반 노드로 고리를 만들 수 없습니다. 반복 노드의 출력에서 앞선 노드로 돌아갈 때만 순환 연결이 허용됩니다.

06

잘못된 연결은 차단

자기 자신 연결, 같은 노드 쌍의 중복 연결, 연결 수 제한 초과, 허용되지 않은 순환은 생성되지 않습니다.

중요: 캔버스에 노드가 보인다고 계산되는 것은 아닙니다. 마나근원 또는 최종발현과 연결이 끊긴 노드는 배치되어 있어도 결과에서 제외됩니다.

04

단위 마법 도감

수치는 마법 버튼이나 노드에 커서를 올려 확인하는 것이 가장 정확합니다. 아래 도감은 각 노드가 조합에서 맡는 역할과 특수 기능을 설명합니다.

  • ✳냉각열을 빼앗아 온도를 낮춥니다. 얼음·동결 계열 조합의 기초가 됩니다.
  • ≋수류물이 흐르고 번지는 성질을 다룹니다. 흐름과 범위를 함께 표현하기 좋습니다.

  • ▰토양흙과 돌의 형태·밀도를 다룹니다. 단단하고 오래 유지되는 조합의 기초입니다.

  • ✚순리회복과 생장처럼 자연스러운 순환을 돕습니다. 안정적이고 오래 지속되는 성질을 가집니다.
  • ◈커스텀분류에 없는 속성이나 개념을 대신합니다. 우클릭으로 이름 변경

05

서클 생성과 스탯 계산

서클은 단순히 화면에 놓인 노드 수로 만들어지지 않습니다. 유효한 경로를 직렬·분기·병합·순환 구조로 분석해 구간별로 나눈 결과입니다.

  • 직렬 경로입력과 출력이 하나씩 이어지는 연속 구간은 하나의 서클이 됩니다.
  • 여러 출력분기·분리에서 현재 서클이 끝나고, 각 출력 대상부터 새 서클이 시작됩니다.
  • 여러 입력병합으로 여러 경로가 모이면 병합 노드부터 다음 서클이 시작됩니다.
  • 반복 고리반복 노드가 닫은 순환 경로는 반복을 포함한 별도 서클로 계산됩니다.
스탯 뜻 직렬·반복 분기와 전체 결과
시전 시간 마법을 완성하는 데 필요한 시간 경로의 값을 합하고 유한 반복 횟수만큼 증가 동시에 갈라진 경로 중 가장 오래 걸리는 값을 사용
불안정성 술식이 흔들리거나 제어하기 어려운 정도 서클 내 합계에 1.15노드 수−1 보정, 반복 횟수는 제외 생성된 서클 가운데 가장 높은 불안정성을 사용
출력 마법이 발휘하는 힘과 효과의 크기 노드 값을 합하고 유한 반복 횟수만큼 반영 모든 분기 경로의 값을 합산
범위 효과가 닿거나 퍼지는 공간적 규모 경로의 배율을 곱하고 유한 반복도 곱셈으로 반영 갈라진 경로 중 가장 넓은 값을 사용
마나 소모 마법 발현에 필요한 총 마나량 노드 값을 합하고 유한 반복 횟수만큼 증가 모든 분기 경로의 값을 합산
지속 시간 발현된 효과가 유지되는 시간 경로의 값을 합하고 유한 반복 횟수만큼 증가 갈라진 경로 중 가장 오래 지속되는 값을 사용

괄호 안의 +/− 수치: 앞 단계에서 선택한 마법사 특성이나 보정 효과가 기본 수치에 더해진 차이입니다. 각 스탯 이름에 커서를 올리거나 키보드로 포커스하면 게임 안에서도 계산 설명을 확인할 수 있습니다.

06

고급 조합과 프리셋

반복 서클 만들기

반복 노드를 경로 끝에 놓고, 반복의 위쪽 출력점을 앞선 노드의 CYCLE 입력점으로 되돌려 고리를 닫습니다.

  1. 순환시킬 노드들을 직렬로 연결합니다.
  2. 경로 끝에 반복 노드를 연결합니다.
  3. 반복 출력에서 앞선 노드의 CYCLE 입력으로 연결합니다.
  4. 반복 노드를 우클릭해 0~99회 중 횟수를 정합니다.

0회 표시는 무한 반복(∞)을 뜻하며 스탯은 1회 기준으로 계산됩니다. 최종발현으로 빠져나가는 경로는 고리 안의 분기·분리 노드에서 따로 이어야 합니다.

분기·분리·병합

세 노드는 마나 흐름의 모양을 바꿉니다. 분기와 분리는 연결 구조는 같지만, 각각 조건에 따른 갈림과 결과의 분배라는 다른 의미를 표현합니다.

  • 분기: 조건별로 다른 마법 경로를 구성할 때 사용
  • 분리: 하나의 결과를 여러 서클에 나누어 전달할 때 사용
  • 병합: 여러 경로를 하나의 후속 경로로 다시 모을 때 사용

프리셋 저장과 불러오기

현재 노드 종류, 위치, 연결, 캡션과 개별 설정을 이름과 함께 저장합니다. 기본 프리셋과 직접 저장한 내 프리셋을 구분해 관리할 수 있습니다.

  • 일반 노드가 하나 이상 있어야 현재 조합을 저장할 수 있습니다.
  • 불러오기는 현재 조합을 선택한 프리셋으로 즉시 교체합니다.

서클이 생기지 않아요

마나근원부터 최종발현까지 화살표 방향으로 따라가 보세요. 중간 연결 하나가 끊겼거나 방향이 반대이면 계산되지 않습니다.

핸들을 연결할 수 없어요

입력·출력 제한을 이미 채웠거나, 중복 연결·자기 연결·일반 순환을 시도했을 가능성이 큽니다. 분기·분리·병합 또는 반복 노드가 필요한 구조인지 확인하세요.

추가한 노드가 스탯에 반영되지 않아요

노드가 완성 경로 밖에 있으면 무시됩니다. 마나근원에서 해당 노드를 거쳐 최종발현까지 실제로 도달할 수 있어야 합니다.

반복 뒤 수치가 예상과 달라요

유한 반복은 대부분의 스탯에 횟수가 반영되지만 불안정성은 반복 횟수를 적용하지 않습니다. 무한 반복은 모든 스탯을 1회 기준으로 계산합니다.

프리셋을 불러오니 작업이 사라졌어요

불러오기는 현재 조합에 덧붙이는 기능이 아니라 전체 교체입니다. 비교하거나 보관할 조합은 먼저 별도 이름으로 저장하세요.

시연 시작 버튼이 비활성화돼요

미리보기에 서클이 하나 이상 표시되어야 합니다. 단순히 노드를 배치한 것만으로는 다음 단계로 진행할 수 없습니다.
