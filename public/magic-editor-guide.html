01

QUICK START

첫 서클을 완성하는 가장 짧은 순서

편집 화면은 선택된 빈 서클 하나로 시작합니다. 필요한 단위 마법을 위에서 아래로 쌓으면 하나의 마법이 그 순서대로 변화합니다. 서클 안의 연결선은 직접 그릴 필요가 없습니다.

  1. 서클이 선택되어 있는지 확인

    선택된 서클은 테두리와 상단 탭이 강조됩니다. 선택이 풀렸다면 서클의 빈 공간이나 상단 탭을 클릭하세요.

  2. 카테고리를 열고 단위 마법 추가

    속성·행동·조절·제어 탭은 여러 개를 동시에 켤 수 있습니다. 도구 모음의 노드를 클릭하면 선택된 단위 노드 바로 아래에 추가됩니다. 단위 노드가 선택되지 않았다면 선택된 서클의 발현 노드 앞에 추가됩니다.

  3. 위에서 아래로 실행 순서 정리

    노드를 끌어 세로 순서를 바꾸세요. 도구 모음에서 직접 끌어 놓으면 포인터 위치에 삽입할 수 있습니다.

  4. 여러 서클이라면 OUTPUT에서 INPUT으로 연결

    서클 아래쪽 OUTPUT 포트에서 다음 서클 위쪽 INPUT 포트로 끌어 간선을 만듭니다. OUTPUT은 서클마다 하나이며, 여러 흐름이 모이는 서클의 INPUT은 필요한 만큼 늘어납니다. 연결된 서클의 첫 단계에는 앞 서클 이름을 가진 합류 노드가 자동으로 생깁니다.

  5. 미리보기와 Total Stats 확인

    단위 마법이나 유효한 입력 합류가 있는 서클은 오른쪽 미리보기와 스탯에 반영됩니다. 조합을 완성한 뒤 이름과 설명을 기록하고 결과를 확인할 수 있습니다.

!

먼저 기억할 한 가지: 단위 마법마다 별개의 마법이 생기는 것이 아닙니다. 위에서 시작한 하나의 마법이 각 단위 마법을 지나며 효과를 얻거나 성질이 바뀝니다. 서클 사이의 연결은 이렇게 다듬어진 결과를 다음 서클로 넘깁니다.

CIRCLES

서클은 하나의 마법을 다듬는 작업대

서클에 들어온 마법은 위에서 아래로 놓인 단위 마법을 차례로 거칩니다. 각 단계는 지금까지 만들어진 마법에 새로운 효과를 더하거나 기존 성질을 바꿉니다. 발현도 이 실행 순서에 포함되는 하나의 단계이며, 서클은 발현이 아니라 마지막 단위 마법을 실행한 뒤 끝납니다.

  • 상단 탭 탭을 끌어 서클을 이동합니다. 우클릭하거나 … 버튼을 누르면 이름·메모·스탯 상세정보가 열립니다.
  • 실행 순서 하나의 마법이 위에서 아래로 이동하며 각 단위 마법의 효과를 차례로 받습니다. 노드는 40px 그리드에 맞춰 정렬되고, 반복 내부만 중첩 깊이당 20px 들여쓰기 됩니다.
  • 발현 노드 푸른 테두리로 표시되며, 배치된 위치까지 만들어진 마법을 외부에 드러냅니다. 다른 단위 마법처럼 순서를 옮길 수 있고 반복 범위 안에 두면 발현도 지정 횟수만큼 반복됩니다. 메모를 쓸 수 있지만 삭제·가중치 적용은 할 수 없습니다.
  • INPUT · OUTPUT 위쪽 INPUT은 앞 서클에서 완성한 마법을 여러 개 받아들일 수 있고, 아래쪽의 하나뿐인 OUTPUT은 현재 결과를 다음 서클 한 곳으로 보냅니다. INPUT에는 다음 연결을 위한 빈 포트가 유지됩니다.
  • 합류 노드 서클을 연결하면 앞 서클의 이름을 가진 합류 노드가 자동으로 생깁니다. 같은 서클 안에서 위치를 옮길 수 있지만 반복 범위 안이나 첫 분기 뒤에는 둘 수 없으며, 직접 삭제하는 대신 서클 사이 연결을 끊으면 함께 사라집니다.

하나의 마법이 서클 사이를 흐르는 법

1 · 시작 앞에서 들어오는 연결이 없는 서클에서 새로운 마법이 시작됩니다.
→
2 · 이어받기 연결된 서클은 합류 노드에서 앞 서클의 마지막 단계 결과를 받아 다음 효과를 이어서 입힙니다.
→
3 · 완료 마지막 단위 마법까지 실행한 뒤, 다음 연결이 있으면 결과를 넘기고 연결이 없으면 전체 마법이 끝납니다.
↗

하나의 서클은 다음 서클 한 곳으로만 결과를 보냅니다. 여러 흐름은 한 서클의 서로 다른 합류 노드로 모을 수 있으며, 합류 사이에 놓인 단위 마법도 순서대로 결과를 바꿉니다. 모든 서클은 출력이 없는 하나의 최종 서클로 이어져야 마법을 완성할 수 있습니다. 연결선은 단위 마법 사이가 아니라 서클 사이에만 직접 그립니다.

서클 추가와 선택

서클 추가는 현재 화면 중앙의 비어 있는 위치에 새 서클을 만듭니다. 빈 내부 공간을 클릭해도 서클이 선택되며 테두리와 탭에 선택 효과가 나타납니다.

이동과 크기 조절

상단 탭으로 이동하고, 선택 상태에 나타나는 테두리 핸들로 크기를 바꿉니다. 여러 서클이 선택되어 있으면 한 서클을 이동할 때 선택된 서클이 함께 움직입니다.

이름과 메모

상단 탭 우클릭 또는 … 버튼으로 상세정보를 열어 이름과 메모를 기록합니다. 메모는 탭에 함께 표시되어 복잡한 그래프의 역할을 구분하기 쉽습니다.

서클 삭제

상세정보의 삭제 버튼이나 선택 후 Delete를 사용합니다. 서클과 내부 노드, 연결이 모두 삭제되므로 전용 확인 창에서 한 번 더 승인해야 합니다.

i

도구 모음의 단위 마법을 클릭하면 선택된 서클 중 화면상 가장 위에 있는 서클 하나에만 추가됩니다. 그 서클의 단위 노드가 선택되어 있다면 가장 아래 선택 노드 바로 다음에 배치됩니다. 정확한 서클과 위치를 지정하려면 노드를 도구 모음에서 원하는 삽입 지점으로 드래그하세요.

05

CONTROL PAIRS

감지·반복·분기로 흐름 제어

감지는 마법이 반응할 조건이나 대상을 정합니다. 반복은 같은 효과를 여러 번 겹치고, 분기는 조건에 따라 현재 위치보다 나중 단계로 건너뜁니다. 반복과 분기는 범위의 시작과 끝이 한 쌍으로 만들어져 항상 함께 움직입니다.

반복 · 들여쓰기로 범위 표시

반복 시작과 반복 끝 사이 노드가 반복 대상입니다. 내부 노드는 중첩 깊이마다 20px 오른쪽으로 들여쓰고 그만큼 폭이 늘어나므로 오른쪽 정렬선은 유지됩니다.

∞ 반복 시작 ×3
▲ 발화
⇧ 증폭
∞ 반복 끝
  • 반복 간선은 표시하지 않으며 들여쓰기가 범위를 나타냅니다.
  • 중첩 반복은 안쪽 구간이 20px씩 더 들여쓰기 됩니다.
  • 시작 노드 상세정보에서 1~99회를 버튼이나 숫자 직접 입력으로 설정합니다.
  • 기본 횟수는 1이며 0과 무한 반복은 지원하지 않습니다.
  • 불안정성은 반복 구간의 일반 단위 마법을 설정 횟수만큼 실행한 것으로 보고 복잡도를 계산합니다. 중첩 반복은 안쪽과 바깥쪽 횟수를 곱하며 제어·발현 노드는 제외합니다.

분기 · 조건에서 목적지로 이동

분기에서 분기 목적지로 이어지는 보라색 선이 오른쪽 레일에 표시됩니다. 선은 둥근 모서리와 꺾쇠 화살표로 진행 방향을 나타냅니다.

∨ 분기 · 대상이 움직일 때
✳ 냉각
◇ 성형
∨ 분기 목적지
  • 시작 노드 상세정보의 메모가 분기 조건으로 표시됩니다.
  • 목적지는 반드시 시작보다 아래에 있어야 하며 여러 정방향 분기 구간은 서로 교차할 수 있습니다.
  • 반복 안에 있어도 실제 들여쓰기 폭을 기준으로 선이 바깥을 우회합니다.
  • 겹치는 분기 구간은 서로 다른 오른쪽 레일을 사용합니다.
  • 표시 스탯은 현재 마법이 낼 수 있는 최대 수치이므로, 조건과 관계없이 사이의 모든 단위 마법을 한 번씩 반영합니다.
  • 목적지 마커는 별도 상세정보를 열지 않습니다.
∞

반복·분기 마커는 항상 시작과 끝이 한 쌍으로 관리됩니다. 한쪽만 복사하면 상대 마커가 자동으로 포함되고, 삭제할 때도 쌍이 함께 정리됩니다. 반복 범위끼리는 서로 교차할 수 없고, 반복과 분기 모두 위쪽으로 거슬러 올라가도록 배치할 수 없습니다.

06

SELECTION & CLIPBOARD

시작 위치가 범위 선택의 대상을 결정

서클과 단위 노드를 실수로 섞어 선택하지 않도록 범위 선택의 범위가 분리되어 있습니다. 드래그를 시작한 위치를 먼저 확인하세요.

IN

서클 안에서 드래그 시작

포인터 아래에서 가장 앞에 있는 서클의 단위 노드만 선택합니다. 다른 서클의 노드와 서클 자체는 선택 대상에서 제외됩니다.

OUT

모든 서클 밖에서 드래그 시작

단위 노드를 제외하고 서클만 선택합니다. 여러 서클을 한 번에 감싼 뒤 함께 이동하거나 복사할 때 사용합니다.

혼합 선택 방지 서클 선택과 단위 노드 선택은 동시에 유지되지 않습니다.
서클 전환 다른 서클의 단위 노드를 선택하면 이전 서클의 단위 선택이 해제됩니다.
발현 선택 발현 노드도 같은 서클의 단위 선택 범위에 포함되며 클릭으로 선택할 수 있습니다.
그룹 이동 여러 서클 또는 같은 서클의 여러 단위 노드를 선택한 뒤 하나를 끌면 함께 이동합니다.

복사와 붙여넣기

1 · 선택 서클 묶음 또는 한 서클 안의 단위 노드 묶음을 선택합니다.
→
2 · 복사 Ctrl/Cmd + C로 구조와 설정을 복사합니다.
→
3 · 붙여넣기 Ctrl/Cmd + V로 독립된 새 항목을 만듭니다.

서클을 복사할 때

크기·위치·이름·메모·내부 노드·발현 메모·설정과, 함께 선택한 서클 사이의 간선이 포함됩니다. 반복해서 붙여넣으면 원본 배치를 유지한 채 매번 40px씩 이동합니다.

단위 노드를 복사할 때

같은 서클에서 선택한 노드만 복사합니다. 반복·분기 마커 한쪽만 골라도 쌍이 자동 포함되며 발현 노드는 단위 복사에서 제외됩니다.

단위 노드를 붙여넣을 때

단위 노드가 선택되어 있으면 선택 블록 뒤에, 서클이 선택되어 있으면 가장 위쪽 선택 서클의 끝에 삽입됩니다. 붙여넣을 대상이 없으면 그래프를 바꾸지 않습니다.

새 복사본의 독립성

서클·노드·간선·반복 및 분기 쌍에는 모두 새 식별자가 발급됩니다. 붙여넣은 항목만 선택되므로 바로 이동하거나 다시 복사할 수 있습니다.

⌘

입력창이나 대화상자에 포커스가 있을 때는 편집기 복사·붙여넣기가 텍스트 입력을 가로채지 않습니다. 시스템 클립보드를 사용할 수 없는 환경에서는 현재 탭의 임시 버퍼가 대신 사용됩니다.

DETAILS & WEIGHT

상세정보에서 이름·메모·가중치 편집

단위 노드는 우클릭 또는 … 버튼, 서클은 상단 탭 우클릭 또는 … 버튼으로 상세정보를 엽니다. 변경 가능한 항목은 노드 종류에 따라 달라집니다. 서클과 노드 모두 메모를 기록할 수 있습니다. 이름만으로 역할이 드러나지 않는 복잡한 조합은 메모를 활용하면 흐름을 훨씬 쉽게 따라갈 수 있습니다.

✎

메모를 흐름의 이정표로 사용하세요. 서클이나 노드의 메모에 “앞 서클의 냉기를 받아 형태를 고정한 뒤 다음 서클로 전달”처럼 받아온 효과·현재 역할·다음 목적을 적거나, “움직이는 대상만 추적”처럼 해당 단계가 필요한 이유를 적어 두면 그래프를 다시 열었을 때도 마법의 진행 과정을 빠르게 이해할 수 있습니다.

일반 단위 노드

카테고리·설명·현재 스탯을 확인하고 공통 메모와 가중치를 설정합니다.

  • 커스텀: 화면에 표시할 이름 편집
  • 가중치 허용 노드: 1~99 스테퍼
  • 상세정보의 삭제 버튼으로 즉시 삭제

반복·분기 시작 노드

반복 시작과 분기 시작 노드에서 쌍 전체의 핵심 설정을 편집합니다.

  • 반복: 횟수 1~99, 기본값 1, 숫자 직접 입력 가능
  • 분기: 메모를 분기 조건으로 사용
  • 제어 카테고리는 가중치 없음
  • 감지·반복·분기는 불안정성 복리 노드 수에서 제외

발현 노드

푸른빛 시스템 노드는 놓인 위치에서 현재까지 만들어진 마법을 발현하며, 상세정보에서 메모를 작성할 수 있습니다.

  • 스탯은 모두 0이며 합산에서 제외
  • 실행 순서를 옮길 수 있고 반복 범위 안에서는 발현 횟수도 반복
  • 가중치와 삭제 기능 없음
  • 서클 복사·프리셋에는 메모와 위치 포함

합류 노드

서클 사이 연결마다 자동으로 생기며, 앞 서클에서 넘어오는 흐름을 이름과 위치로 보여줍니다.

  • 앞 서클의 이름을 표시하고 이름 변경도 즉시 반영
  • 같은 서클 안에서 이동 가능, 반복 범위 내부와 첫 분기 뒤에는 배치 불가
  • 직접 삭제·메모·가중치 설정 없음
  • 합류 전 구간과 앞 서클은 동시에 진행되고, 합류 뒤 노드는 병합된 결과에 이어서 적용

서클

서클 이름·메모와 해당 서클의 계산 스탯을 한 화면에서 관리합니다.

  • 이름과 메모는 상단 탭에 표시
  • 메모에 입력 효과·서클 역할·다음 전달 목적을 기록하면 전체 흐름을 파악하기 쉬움
  • 삭제 시 내부 노드·연결도 함께 제거
  • 삭제 전 전용 확인 모달 표시

노드 가중치 규칙

가중치는 같은 단위 마법의 효과를 여러 겹 적용하는 값입니다. 기본값 1은 노드명에 표시하지 않고, 2 이상부터 이름 뒤에 ×N으로 표시합니다.

기본 스탯 → 외부 노드 보정 → 노드 경계값 → 가중치 → 반복 횟수

CALCULATION

서클과 전체 스탯 읽기

스탯은 이 구조가 가장 온전히 작동했을 때 낼 수 있는 최대 결과를 보여줍니다. 각 서클의 수치는 앞 서클에서 합류한 결과와 현재 서클의 마지막 단위 마법까지 누적된 값을 나타내고, Total Stats는 모든 흐름이 모이는 최종 서클의 완성값을 보여줍니다.

시간

시전 시간은 마법을 완성하는 데 걸리는 시간이고, 지속 시간은 완성된 효과가 유지되는 시간입니다.

효과

출력은 효과의 세기, 범위는 효과가 닿는 넓이나 거리를 나타냅니다.

비용

마나 소모는 이 마법을 한 번 완성하는 데 필요한 마나의 총량입니다.

위험

불안정성은 같은 결과를 안전하게 재현하기 얼마나 어려운지 나타냅니다.

↑

분기가 있어도 최대 결과를 표시합니다. 실제 실행에서는 조건에 따라 일부 단계를 건너뛸 수 있지만, 화면의 스탯은 현재 구조가 낼 수 있는 최대치를 보여주기 위해 분기 사이의 단위 마법을 모두 한 번씩 반영합니다. 반복 구간은 설정한 횟수만큼 효과가 겹치고, 불안정성의 복잡도도 함께 증가합니다.

정확한 계산 규칙

×

불안정성은 기본 불안정성 합계 × 1.1유효 노드 수−1로 계산합니다. 반복 안의 일반 단위 마법은 반복 횟수만큼 유효 노드 수에 더하고, 중첩 반복은 각 횟수를 곱합니다. 기본 불안정성 값 자체를 반복해서 더하지는 않으며, 감지·반복·분기와 발현은 이 노드 수에서 제외됩니다. 서클이 합류하면 선행 흐름 중 가장 높은 불안정성을 이어받으므로, 합류 뒤의 안정 노드가 이미 발생한 선행 불안정성을 낮추지는 않습니다.

스탯 서클 내부 전체 흐름
시전 시간 단위 마법의 시간을 더하고 반복 횟수만큼 반영 합류에서는 가장 오래 걸린 흐름을 사용하고, 합류 뒤 시간은 이어서 더함
불안정성 기본 불안정성을 한 번씩 더한 뒤 반복 실행 횟수를 포함한 유효 노드 수로 복리 증가 완성된 서클 중 가장 높은 값 사용
출력 단위 마법의 출력을 더하고 반복 횟수만큼 반영 합류하는 흐름의 출력을 더하고 이후 출력을 이어서 더함
범위 단위 마법의 범위 값을 차례로 곱하고 반복 횟수만큼 반영 합류에서는 가장 넓은 흐름을 사용하고, 이후 범위 값은 차례로 곱함
마나 소모 단위 마법의 소모량을 더하고 반복 횟수만큼 반영 합류하는 모든 흐름과 이후 단위 마법의 소모량을 더함
지속 시간 단위 마법의 지속 시간을 더하고 반복 횟수만큼 반영 합류에서는 가장 오래 유지되는 흐름을 사용하고, 이후 지속 시간을 더함
10

불안정성이 10을 넘으면 위험 구간입니다. 수치가 더 높아질수록 시전에 실패하거나, 위력·범위·대상이 흔들리는 등 예상하지 못한 결과가 생길 가능성이 커집니다. 현재 편집기는 실패 확률을 직접 굴리지는 않으며, 이 수치는 마법의 설정상 위험도를 판단하는 기준입니다.

M

최대 마나 제한이 활성화된 경우 하단 내비게이션에 마나 소모 / 최대 마나가 표시됩니다. 기본 최대 마나는 100이고, 촉매로 보석을 선택하면 40이 늘어나 최대 140이 됩니다. 마나 소모가 최대치를 넘어도 조합은 계속 편집할 수 있지만 마법 완성 단계로는 진행할 수 없습니다. 제한이 없는 환경에서도 마나 소모 수치 자체는 계속 계산됩니다.

0

단위 마법과 입력 합류가 모두 없는 빈 서클은 유효한 계산 서클이 아닙니다. 단위 마법이 없어도 유효한 합류가 있다면 앞 서클의 결과를 이어받는 서클로 계산됩니다. 감지·반복·분기와 발현은 불안정성 복리의 유효 노드 수에서 제외됩니다.

서클 상세 스탯

서클 상단 탭의 상세정보에서 그 서클 마지막 단계까지 누적된 스탯을 확인합니다. 앞 단계 보정이 있으면 기준값과의 차이가 함께 표시됩니다.

노드 툴팁 스탯

도구 모음이나 노드에 마우스를 올리면 그 노드의 설명과 스탯을 확인할 수 있습니다. 가중치와 현재 외부 보정이 미리 반영됩니다.

프리셋 불러오기

선택한 프리셋으로 현재 그래프 전체를 교체합니다. 기존 조합에 덧붙이는 기능이 아닙니다.

  • 보관할 현재 작업은 먼저 별도 저장
  • 기본 프리셋과 내 프리셋을 구분
  • 삭제는 내 프리셋에만 제공
  • 브라우저 로컬 저장소에 보관

전체 초기화

현재 그래프와 시그니처 정보를 지우고 선택된 빈 서클 하나가 있는 초기 상태로 돌아갑니다.

  • 내 프리셋은 함께 삭제되지 않음
  • 편집 중 그래프는 복구되지 않음
  • 필요한 조합은 초기화 전에 저장

이름·설명 기록과 결과

모든 서클이 하나의 최종 서클로 이어지면 마법 이름과 설명을 기록하고 조합 결과를 확인할 수 있습니다.

  • 입력 중 취소하거나 이전 단계로 돌아와도 이름과 설명 초안 유지
  • 마법 이름·설명·그래프·서클 문양·Total Stats 표시
  • 세로로 긴 그래프는 실제 길이만큼 결과 영역 확장
  • PNG도 동일한 전체 그래프 비율로 내보내기

노드를 추가할 수 없어요

먼저 서클을 선택하세요. 여러 서클을 선택했다면 클릭 추가는 화면상 가장 위의 서클만 대상으로 합니다. 단위 노드가 선택되어 있으면 그중 가장 아래 노드 다음에 추가됩니다. 원하는 서클에 직접 끌어 놓는 방법도 있습니다.

범위 선택 대상이 달라요

드래그 시작점이 서클 내부인지 확인하세요. 내부에서 시작하면 그 서클의 단위 노드, 모든 서클 밖에서 시작하면 서클만 선택됩니다.

서클이 결과에 안 보여요

발현 외에 사용자 단위 노드가 하나 이상 있어야 유효합니다. 반복·분기 마커의 쌍이 유효한지도 확인하세요.

붙여넣기가 되지 않아요

단위 노드 붙여넣기에는 대상 서클이 필요합니다. 입력창이나 대화상자 안에서는 텍스트 붙여넣기가 우선합니다.

가중치가 없어요

감지·반복·분기는 제어 카테고리라 가중치를 사용하지 않습니다. 발현도 시스템 노드이므로 제외됩니다.

분기선이 노드에 가려져요

분기선은 반복 들여쓰기와 중첩 깊이를 반영해 오른쪽 바깥 레일을 사용합니다. 서클 폭이 너무 좁다면 선택 후 크기 조절 핸들로 넓혀 보세요.

구조를 먼저, 수치는 그다음

먼저 서클마다 읽기 쉬운 실행 순서를 만들고 필요한 서클만 연결하세요. 그다음 메모와 분기 조건으로 의도를 기록하고, 마지막에 가중치·반복 횟수와 Total Stats를 조정하면 복잡한 조합도 유지하기 쉬운 형태로 완성할 수 있습니다.
